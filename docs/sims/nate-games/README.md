# Nate's games

Save files of Nate's own games, for the simulator to replay (`pnpm sim --replay <file>`) and for a later session to study how he wins (the top-tier bot above the Marshal, decided Oct 9).

How to add one: in the game, **Settings → Save game → Save to a file**, and put the file here with any name (for example `2026-10-09-wyrmland-6.json`). A game started fresh in the browser carries every turn's orders; a game loaded from a slot made under older rules doesn't.
