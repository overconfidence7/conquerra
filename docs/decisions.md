- 2026-10-02: How maps are built: a fine mesh of a few thousand small cells → land and water from noise (a continent with bays, seas, lakes, island chains) → territories grown from spread-out seeds over a "wobbly" cost field and evened out → mountain ranges cut along territory borders, leaving passes → rivers along borders, always downhill → sea lanes (every island first, then shortcuts) → provinces → capitals → drawing data.
- 2026-10-02: Every generated map must pass the map checks (all territories connected; no slivers or blobs; provinces of a sensible size for the map; fair capitals; a minimum number of choke points and sea lanes) or the map maker tries the next seed ("embervale#2", ...). Embervale took 2 tries, Greatmarch 1.
- 2026-10-02: New `sea` border type for sea lanes: attack ×0.75 (rules.json). Harder than a pass (×0.85) or a river (×0.8).
- 2026-10-02: Fair capitals: maps store a capital layout per player count (similar distance to the nearest rival, within 1 border; similar income nearby, within 30%; always on plains). The game uses the layout when there is one.
- 2026-10-02: Map drawing data (outlines, water, mountains, passes, rivers, sea lanes, label points, building/castle sites, biome grid, height map, province label lines, decorations) is an optional `geometry` block on the map.
